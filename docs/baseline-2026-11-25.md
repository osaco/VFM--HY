## Truth fixes in this revision

* **Track popovers use libVLC's own track descriptions.** `libvlc_audio_get_track_description`
  and `libvlc_video_get_spu_description` are now bound; each popover row keeps the real track
  id, so sparse ids select correctly and an empty engine list shows no rows. The previous
  "Audio 1 / Sub 1" labels were positional guesses.
* **Subtitle outline width is rendered.** The four outline copies use a
  `subtitle-outline-width` property fed from the cue style, instead of a fixed 2 px.
* **The default layout matches the shipped bar.** `Layout::default()` now lists the four tail
  controls the player actually draws (audio, subtitles, settings, queue). Previously a fresh
  install hid the queue and settings buttons because they were absent from the default layout.
* **Tail-button order is applied.** `Layout::trailing_slots` assigns each rendered control a
  slot measured from the right edge; reordering in the customizer moves the real buttons.
* **RTSP is a real RTSP chain.** The RTSP stream preset now emits
  `#transcode{…}:rtp{sdp=rtsp://…}` and reports an `rtsp://` viewer URL; it no longer labels an
  HTTP stream as RTSP.
* **Branding.** The placeholder VLC-style cone was replaced with an original VFM monogram
  (`assets/branding/vfm-256.png`, `vfm-512.png`, `vfm.ico`).

## Still not done

The remaining gaps are listed in `PHASES.md` and `docs/phase-11.md`. In particular: seek-thumbnail
generation, rotation/flip output, capture-device enumeration, full 20-control bar rendering,
DPI 125/150/200 % and multi-monitor screenshots, 4K measurement, high-contrast mode, EXE icon
embedding and installer signing are still open. None of them is claimed as working here.
